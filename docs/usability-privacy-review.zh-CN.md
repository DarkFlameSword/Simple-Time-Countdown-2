# 可用性、无障碍与隐私评审

[**English**](usability-privacy-review.md) | [**简体中文**](usability-privacy-review.zh-CN.md)

本文对照业界常用的可用性、无障碍和隐私准则检查 Simple Time Countdown，并记录据此所做的改动。这是项目的自我评估，并非认证。

- **可用性**：Jakob Nielsen 十大可用性原则；ISO 9241-110:2020（交互原则）；ISO 9241-11:2018（可用性：有效性、效率、满意度）。
- **无障碍**：ISO 9241-171 与 WCAG 2.2（ISO/IEC 40500 即 WCAG 2.0）。
- **隐私与权限**：ISO/IEC 29100（隐私框架），以及 Google 为应用发布的实践（只申请必需的权限、在使用时申请、妥善处理拒绝、不在锁屏上显示敏感内容、最小化并公开数据）。Google 的指南面向 Android 和 Web，这里将其原则用于 Windows 桌面应用。

标注 **新增** 的条目是本次评审加入的，其余为原有能力。

## 1. Nielsen 十大可用性原则

| # | 原则 | 应用如何做到 |
| --- | --- | --- |
| 1 | 系统状态可见 | 每张卡片实时倒计时并显示状态标签（正常、即将到期、紧急、已过期）。底部显示列出的倒计时数量；保存出错时显示“正在重试……”。**新增**：归档、恢复或删除后，底部说明刚才发生了什么（“已归档“论文”。”）。**新增**：所选时间已经过去时，编辑窗口会提示。 |
| 2 | 系统与现实世界相匹配 | 用语直白，以天/小时/分钟计时，使用用户所在地区的日期格式和本地化的时区名称；夏令时造成的时间空缺或重复会用文字说明，而不只是给出时差。 |
| 3 | 用户控制与自由 | **新增**：归档、恢复和删除都可以在底部撤销，或按 `Ctrl+Z`。**新增**：按 `Esc`、**取消** 或 `Alt+F4` 关闭编辑窗口时，若已填写内容会先询问是否放弃。**新增**：在面板任意位置按 `Esc` 都能先清除再关闭搜索。设置即时生效，用 **完成** 关闭，无需逐项确认。 |
| 4 | 一致性与标准 | 遵循 Windows 惯例：`Ctrl+N`、`Ctrl+F`、`Ctrl+E`，**新增** `Ctrl+Z` 和 `F1`；`Enter` 保存，`Esc` 取消；单击托盘图标即可打开。图标按钮、文字链接、主要操作各只有一种样式。 |
| 5 | 预防错误 | 必填标记、字数上限（达到 80% 时显示计数）、受支持的日期范围，并拒绝夏令时空缺中的时间。打开编辑窗口前就检查面板 5000 条的上限，不会让已输入的内容白费。**新增**：删除确认使用警告图标、默认选项为 **否**，并建议改为归档。**新增**：保存前提示截止时间已经过去。 |
| 6 | 识别而非回忆 | 每个图标按钮都有名称和包含快捷键的提示。空列表会告诉用户下一步做什么（**新增**：“点击 + 或按 Ctrl+N”“按 Esc 可清除搜索”）。 |
| 7 | 灵活高效 | 键盘快捷键；`Home`/`End`/`Page Up`/`Page Down` 在卡片间移动；托盘菜单中的“新建倒计时”；默认提醒和时区；置顶。 |
| 8 | 简约美观 | 一张纸面、一种强调色。卡片上的操作按钮在悬停或获得焦点前保持低调；提示只在需要时出现。 |
| 9 | 帮助用户识别、诊断并从错误中恢复 | 校验信息显示在字段下方，焦点移到第一个出错的字段。保存文件无法读取时从备份恢复并保留原文件；保存失败会自动重试。**新增**：删除可以撤销；搜索无结果时说明如何返回。 |
| 10 | 帮助与文档 | **新增**：`F1` 和 **设置 > 关于 > 使用指南** 以界面语言打开使用指南。中英双语 README，并附常见问题。 |

## 2. ISO 9241-110:2020 交互原则

| 原则 | 依据 |
| --- | --- |
| 适合用户的任务 | 在一个对话框内即可创建倒计时，并带有合理的默认值（明天、默认提醒和时区）。面板可以浮在其他窗口之上、停留在其后，或在托盘中待命。 |
| 自我描述性 | 每张卡片都有标签、单位和状态文字；提示同时说明操作和对应的卡片；设置项用说明文字解释其效果（桌面层、对比度主题下的不透明度、**新增** 通知标题）。 |
| 符合用户预期 | 标准的 Windows 按键和对话框。关闭按钮的提示会说明它是关闭到托盘还是退出。置顶卡片排在最前，其余按截止时间排序。 |
| 易学性 | 提示中显示快捷键。**新增**：空列表中的提示，`F1` 打开使用指南。 |
| 可控性 | 面板的位置、大小、不透明度、层级、语言、提醒、阈值和开机启动都由用户决定。**新增**：撤销和放弃确认。滑块和数值都可以用键盘操作。 |
| 使用错误的鲁棒性 | 行内校验；在安全保留之前绝不覆盖状态文件；原子保存并保留备份。**新增**：撤销、默认为 **否** 的删除确认、放弃确认。 |
| 用户投入度 | 独特的“案录”风格与平和的视觉（除用户自己的提醒外不弹窗）。 |

ISO 9241-11 以特定使用情境下的有效性、效率和满意度衡量可用性。目前尚未进行正式的用户测试，建议的测试方案见[第 6 节](#6-已知局限与后续工作)。

## 3. 无障碍（ISO 9241-171、WCAG 2.2）

- 所有操作都可用键盘完成，并有可见的焦点框（WCAG 2.1.1、2.4.7）。
- 屏幕阅读器可以读到每张卡片的一句话概要、每个控件的名称、带单位的滑块数值，以及计数、校验、保存问题和（**新增**）撤销提示的实时播报（WCAG 4.1.2、4.1.3）。
- 支持 Windows 对比度主题；在任何面板不透明度下，文字颜色都满足 AA 级对比度（WCAG 1.4.3、1.4.11）。
- 文字不小于 12 DIP，遵循 Windows 文本大小设置，换行而不截断（WCAG 1.4.4、1.4.10）。
- **新增**：鼠标指针或键盘焦点停在撤销提示上时，它不会消失，用户无需匆忙操作（WCAG 2.2.1 可调整的时限）。

## 4. 隐私与权限

### ISO/IEC 29100 隐私原则

| 原则 | 应用如何做到 |
| --- | --- |
| 同意与选择 | 开机启动默认关闭，由用户自行开启；MSIX 的启动任务默认禁用。**新增**：通知可以不显示倒计时标题。卸载时询问是否删除用户数据。 |
| 目的合法且明确 | 数据只用于显示倒计时和发送用户自己设置的提醒。**新增**：“设置 > 隐私与数据”中写明了这一点。 |
| 收集限制 | 只保存用户输入的内容和面板设置；无需账户，不收集设备标识或使用数据。 |
| 数据最小化 | 日志从不包含倒计时内容。**新增**：日志中的用户文件夹（含账户名）写为 `%USERPROFILE%`。**新增**：可不在通知中显示标题。 |
| 使用、保留与披露限制 | 不向任何地方发送数据，应用没有任何联网代码。日志保留 7 天；无法读取和被截短的状态文件各最多保留 5 份。 |
| 准确性与质量 | 输入经过规范化和校验；加载时修复已保存的文件，写入时采用原子操作并保留备份。 |
| 公开、透明与告知 | **新增**：“设置 > 隐私与数据”中的简明说明；README 的“数据与隐私”一节，以及本文。 |
| 个人参与与访问 | **新增**：**打开数据文件夹** 可直接看到 `state.json`（可读的 JSON），便于备份或迁移到另一台电脑；MSIX 版会打开其私有存储。倒计时可以逐条删除，卸载时也可删除全部数据。 |
| 问责 | **新增**：CONTRIBUTING 中列出了今后修改需遵守的隐私规则，并有测试检查日志脱敏。 |
| 信息安全 | 数据位于每个用户自己的文件夹，沿用 Windows 默认的用户权限；原子写入；应用以普通用户身份运行；按用户安装，无需管理员权限；CI 使用只读令牌和固定版本的 Action。 |
| 隐私合规 | 不含第三方 SDK 或统计分析；随应用附带 .NET 运行时的许可声明。 |

### 权限实践（参照 Google 指南）

| 实践 | 应用如何做到 |
| --- | --- |
| 只申请必需的权限 | 清单为 `asInvoker`（从不提权）；按用户安装；MSIX 只声明每个打包桌面应用都必需的 `runFullTrust`。 |
| 在使用功能时才申请 | 只有用户勾选 **开机时启动** 时才会注册自启动。通知通过托盘图标发出，不需要额外授权。 |
| 说明原因 | 每个涉及隐私的设置都有说明文字。 |
| 妥善处理拒绝 | Windows 拒绝开机启动时，复选框会恢复原状并说明原因；无法使用桌面层时，面板恢复为普通窗口并告知用户。通知遵循“专注”/“请勿打扰”。 |
| 允许撤回 | 每个选择都可以在设置中或 Windows“设置 > 应用 > 启动”中撤回（MSIX 版提供直达链接）。 |
| 不在锁屏上显示敏感内容 | **新增**：可以关闭 **在通知中显示倒计时标题**。 |
| 最小化并保护日志 | **新增**：用户文件夹路径脱敏；日志只保存在本机且很快清理。 |

## 6. 已知局限与后续工作

- 撤销只涵盖归档、恢复和删除，不包括编辑和置顶。编辑本身可以再次修改来还原，且编辑窗口会保护未保存的内容。
- 应用内没有导出、导入或“删除全部数据”按钮；数据文件夹按钮、逐条删除和卸载时的删除数据选项涵盖了访问和删除的需要。
- 不显示标题的通知仍会显示应用名称；通知是否出现在锁屏上由 Windows 通知设置决定。
- 尚未与真实用户一起衡量可用性（ISO 9241-11）。建议找 5–8 位参与者完成“新建一个带提醒的倒计时”“找到并编辑一条倒计时”“归档后再找回”“让通知不显示标题”等任务，记录任务成功率、用时和 SUS 评分，并在各版本间跟踪。
